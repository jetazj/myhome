# myhome

个人工作仓库。用来存放日常的代码、笔记和配置。

## 目录说明

| 目录 / 文件 | 用途 |
| --- | --- |
| `README.md` | 本文件，仓库说明 |

## 使用

```bash
git clone git@github.com:jetazj/myhome.git
```

日常提交：

```bash
git add .
git commit -m "说明这次改了什么"
git push
```

## 约定

- 提交信息用一句话说清「改了什么、为什么」，不要写 `update`、`fix`。
- 密码、密钥、令牌一律不进仓库，统一放在 `.gitignore` 里。
